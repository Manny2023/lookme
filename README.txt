TEDYCAM PRO - SIMPLE

TELÉFONO CÁMARA
1. Abre TedyCam desde HTTPS.
2. Toca CÁMARA.
3. La primera vez escribe una frase privada. Se guarda.
4. Toca ENCENDER.
5. Acepta cámara y micrófono.

LAPTOP / CELULAR VISOR
1. Abre la misma TedyCam.
2. Toca VER.
3. Escribe la misma frase.
4. Toca CONECTAR.
5. TedyCam no abre la cámara del visor.

IMPORTANTE
- La PWA necesita HTTPS.
- El teléfono cámara debe seguir activo mientras transmite.
- Baja el brillo para reducir consumo/calor.
- No dejes un teléfono con batería dañada o hinchada cargando sin supervisión.
- Esta versión está diseñada para una cámara por frase. Para otra cámara simultánea, usa otra frase.
